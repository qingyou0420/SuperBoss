## 1. 总体架构（四层）

```
┌─────────────────────────────────────────────────────────────┐
│ 接入层（当前：OWNER Windows 本机）                              │
│  app.localhost │ HTTPS │ Docker Desktop │ 不开放外网             │
└──────────────────────────┬──────────────────────────────────┘
                           ▼
┌─────────────────────────────────────────────────────────────┐
│ 应用层（Docker Compose 编排）                                 │
│  云盘服务 │ 项目管理 │ 成本核算 │ 认证中心(JWT+RBAC)           │
└──────────────────────────┬──────────────────────────────────┘
                           ▼
┌─────────────────────────────────────────────────────────────┐
│ 智能体层（霜月 Agent 服务 —— 仅 OWNER 会话）                   │

└─────────────────────────────────────────────────────────────┘
```

## 2. 权限模型

### 2.1 角色
- **OWNER**：唯一，硬编码不可降级，全权限
- **STAFF**：仅所属项目内的受限读写（浏览/下载资料、上传凭证与排班、提交提问）

### 2.2 双重过滤
- **行级**：所有业务 SQL 强制附加 `project_id` 条件（查询构造层统一注入，非手工编写）
- **列级**：成本、利润、收益字段在序列化层按角色剔除，仅 OWNER 可见

### 2.3 请求校验链（每次请求必走）
```
JWT 解析(user_id+role) → RBAC 策略表校验 → 数据行过滤 → 审计日志
```

### 2.4 关键原则
- 权限判断永远在后端做，不信任前端、不信任提示词
- 霜月 Agent 调用内部工具时携带调用者身份，工具内部二次校验
- Agent 网关层直接拒绝非 OWNER 的会话请求，员工无任何大模型调用入口

## 3. 认证与会话

```
打开系统(无公开注册页) → 本地用户名/密码校验
→ 匹配内部白名单账号 → 签发双Token(Access 2h / Refresh 14d)
```

账号生命周期：
- **初始化**：交互式命令创建唯一 OWNER，不把密码写入环境变量或日志
- **入职**：老板后台添加本地 STAFF，交付一次性临时密码并强制首次改密
- **在职**：角色/项目成员调整即时生效，JWT 短时效强制刷新
- **离职**：一键禁用 + Refresh Token 吊销

## 4. 私有化访问控制（四道闸）

| 层 | 措施 |
|---|---|
| 1 | 当前仅 OWNER 本机访问 `app.localhost`，不做路由器端口映射 |
| 2 | Docker 服务不暴露到公共网络 |
| 3 | 本地账号白名单，无公开注册，禁用立即失效 |
| 4 | RBAC + 行级过滤，应用层兜底 |

备案完成前不宣称腾讯云、公司内网多人访问、公共域名或 Moonbox 门户已经接入；这些属于
后续独立部署任务。

## 5. 两条异步协作流转

**成本凭证流**：
员工上传 → 霜月 OCR/归类/生成入账草稿 → 提醒老板 → 老板一键确认入账

**提问需求流**：
员工表单提交 → 霜月汇总归类为老板待办 → 老板回复（霜月可代拟稿）→ 以公司名义推送员工

## 6. 文档版本链数据流

```
初版上传(锁定存档) → 修订版 v2..vn(记录修改日期/人)
→ 老板标记定稿 → 霜月生成最终版vs初版差异归纳报告

每次修订自动生成：修改日期时间轴 + 修改要点(≤3条) + 版本说明卡
```

## 7. 部署架构

- 单机 4C8G 腾讯云轻量应用服务器
- Docker Compose 编排全部服务（web / server / agent / postgres / minio / redis / nginx）
- `deploy.sh`：git pull → compose build → migration → 滚动重启 → 失败回滚
- 备案过渡期：公网 IP + 临时证书 + IP 白名单；备案后仅改 Nginx 配置切 nightforest.com + 免费 SSL

## 8. 安全清单（上线前必查）

- [ ] 大模型 API 密钥仅存服务端环境变量，不进代码库
- [ ] MinIO 预签名 URL 设短有效期 + 权限校验
- [ ] 上传文件走 ClamAV 病毒扫描
- [ ] 审计日志覆盖：上传/下载/成本修改/凭证确认/账号变更
- [ ] 数据库每日备份（pg_dump + MinIO 快照 → COS 冷备）
- [ ] 员工侧路由表不含任何 Agent 相关页面与 API
- [ ] 收益表 API 层硬锁 `role=OWNER`
