# SuperBoss 漳州分公司 · 第一版前端设计

设计依据：[产品规划](./SuperBoss-产品规划-漳州分公司-V1.md)。视觉方向为简洁的企业内部工作台：中性灰底色、企业蓝主色、紧凑表格与统一的 6px 卡片圆角。首页优先展示项目阶段、节点日期、准备事项和变更记录。

根据本轮反馈，取消首页大幅摘要卡、宣传式经验卡与英文装饰标题。页面采用“会务项目”“经营总览”“财务台账”等直接业务名称；重复说明删除，仅保留数据来源、操作校验和财务口径等必要信息。

## 可交互预览

入口：`http://127.0.0.1:4176/design.html`。在 `web` 目录运行：

```powershell
npx vite --config vite.design.config.ts
```

独立构建：

```powershell
npx vite build --config vite.design.config.ts
```

构建输出为 `web/design-dist`。这是独立设计入口，正式应用仍使用原入口和路由。

## 页面与主要操作

- **工作台**：当前项目、即将到来的节点、本周日程、项目动态。点击进入项目；调期结果同步到首页的项目日期和动态。
- **会务项目**：项目目录与阶段时间线并排展示。查看当前工作、下一步准备、定稿与公示材料。调期抽屉呈现原因、原日期、新日期以及受影响的后续阶段；已完成阶段保留原记录。阶段完成需要材料和明确确认。
- **业务地图**：区域关系示意与名录列表切换，支持区县、街道和关键词筛选，侧栏呈现小区来源、联系人及沟通记录。尚无经纬度时不绘制虚构点位。
- **经验知识库**：按工作阶段查阅老板整理的项目经验，查看版本、修改理由和参考依据，下载明确标注的演示文件。正式版本需要完整导入老板确认的项目经验链路。
- **经营总览**：经营曲线、现金收支、业务构成、后续项目和待回款。将经营成果和实际现金分开呈现，示例数据用于确认展示口径。
- **财务台账**：项目金额与成本、资料批次登记、奖励结算。提供成本试算、重复记录提示和凭证登记交互。超预算抵扣、尾款到账和每月 20 日结算规则可在界面查看。
- **霜月侧栏**：记录、查询与排期辅助的交互入口，关联来源页面。第一版文件制作和审核继续使用 Kimi / WorkBuddy。
- **招投标代理**：保留入口，具体流程后续设计。

## 查看身份

右上角的身份切换是设计评审工具，正式产品应由登录身份决定。

- 老板：完整业务视图、日程修改、财务资料登记、知识整理入口。
- 项目主负责人：执行部视图，并可修改自己负责的项目日期、确认阶段完成。
- 普通员工：流程、日期、文件、业务名录及知识库；项目中可见确认的服务金额，不展示公司财务明细或奖励台账。
- 股东：经营报表与项目进度，只读查看。

## 数据与实现边界

业务名录保留两份原始 Excel 的 304 条来源记录：龙文区 102 条、芗城区 202 条。这个数量是来源记录数，不代表已经核验的独立小区总数；同名和来源差异不自动合并。电话已脱敏，缺失信息显示待补充。

项目、经营数字、奖励、知识内容和联系人沟通记录均为设计示例。预览内操作仅保存在当前页面会话，刷新后恢复；文件选择只展示文件名，不上传或识别实际资料。示例导入使用预设数据，独立演示去重和登记，不改变项目账本。霜月响应是界面演示，尚未接入模型。

本轮交付用于确定页面布局与操作路径。正式接入还需完成后端身份权限、持久化、真实文件存储、通知同步、完整知识链路导入，以及财务导入和日期依赖校验。示例流程不作为现行法规或法定日期依据。
